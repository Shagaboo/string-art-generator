# StringArtGenerator

Генератор string art из фотографий с оптимизированным Go backend для высокой производительности.

## Особенности

- 🎨 Генерация string art из черно-белых фотографий
- ⚡ Высокая производительность благодаря Go backend
- 🖼️ Настройки яркости, контраста и инверсии
- 📐 Различные формы расположения гвоздей (круг, прямоугольник, случайное)
- 📊 Настраиваемое количество гвоздей и линий
- 🎯 Оптимизированный алгоритм для детализации портретов
- 📱 Адаптивный дизайн для мобильных устройств
- 💾 Экспорт в PNG и SVG (для CNC машин)

## Технологии

- **Frontend**: Next.js, React, TypeScript
- **Backend**: Go (Golang)
- **Алгоритм**: Error-based residual image с оптимизацией кандидатов

## Установка

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
go mod download
go run .
```

Backend запустится на порту `9000`.

## Использование

1. Загрузите черно-белое изображение
2. Настройте параметры:
   - Количество гвоздей (рекомендуется 2000-3000)
   - Количество линий (рекомендуется 20000-50000)
   - Яркость и контраст
   - Форма расположения гвоздей
3. Нажмите "Запустить" для начала генерации
4. Дождитесь завершения и скачайте результат

## Производительность

Благодаря оптимизациям Go backend:
- Проверка только 300 кандидатов вместо всех гвоздей
- Прямая проверка без overhead worker pool
- Кэширование линий
- Batch обработка для SSE

Скорость генерации: **10-20x быстрее** чем оригинальная JavaScript версия.
